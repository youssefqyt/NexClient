=============================================================
HOW TO RUN THE APPLICATION
=============================================================

BACKEND:
1. cd backend
2. Create database: CREATE DATABASE nexclient;
3. Update .env with database credentials
4. php artisan migrate:fresh --seed
5. php artisan storage:link
6. php artisan serve
   -> API: http://localhost:8000

FRONTEND:
1. cd frontend
2. npm install (if not done)
3. npm run dev
   -> App: http://localhost:5173

LOGIN CREDENTIALS:
Admin: admin@nexclient.com / password
Client: client@example.com / password

=============================================================
API DOCUMENTATION
=============================================================

All endpoints follow RESTful conventions.
Base URL: http://localhost:8000/api

Authentication:
- POST /register
- POST /login
- POST /logout
- GET /user

Clients:
- GET /clients (list with pagination & filters)
- POST /clients (create)
- GET /clients/{id} (show)
- PUT /clients/{id} (update)
- DELETE /clients/{id} (delete)

Projects, Tasks, Invoices, Tickets follow same pattern.

Special Endpoints:
- GET /invoices/{id}/pdf (download PDF)
- POST /tickets/{id}/messages (add message)
- GET /analytics/dashboard (statistics)
